# MP3 녹음기 (Mp3Recorder)

안드로이드용 **MP3 녹음기 + MP3 플레이어** 통합 앱.

## 📲 앱 다운로드 (핸드폰에서)

**[⬇ 최신 APK 다운로드](../../releases/latest)** ← 핸드폰 브라우저로 이 링크를 열고 `.apk` 파일을 받아 설치하세요.

> 설치 시 "출처를 알 수 없는 앱" 허용이 필요합니다.
> (설정 → 보안 → 출처를 알 수 없는 앱 설치 허용)

## 주요 기능

### 녹음
- 진짜 **MP3(128kbps CBR)** 로 녹음 — LAME 3.100 인코더 (NDK)
- 일시정지 ↔ 재개 무제한 반복 (하나의 이어진 MP3로 저장)
- 화면 꺼짐/백그라운드 녹음 유지 (Foreground Service)
- 알림·잠금화면에서 일시정지/재개/정지 제어
- 통화 수신 시 자동 일시정지, 통화 종료 후 자동 재개
- 저장 위치: `음악/MP3녹음기/`

### 재생
- 기기 음악 라이브러리 (내 녹음 / 즐겨찾기, 검색·정렬)
- **반복 3종**: 전체 반복 🔁 / 한 곡 반복 🔂 / **A-B 구간 반복**
- 셔플, 배속 0.5x~2.0x, ±10초 건너뛰기
- 이어듣기(30분 이상 파일), 슬립 타이머
- 재생목록 + 폴더 불러오기, 즐겨찾기 ♥
- 백그라운드 재생, 잠금화면·블루투스 제어 (Media3)
- 공유 (카카오톡, 네이버 클라우드 등)

## 빌드

```
JDK 17, Android SDK 35, NDK r27c, CMake 3.22.1 필요
gradle assembleDebug
```

- Kotlin + Jetpack Compose (Material 3), minSdk 29 (Android 10+)
- LAME은 LGPL — 동적 라이브러리(liblamejni.so)로 링크됨
